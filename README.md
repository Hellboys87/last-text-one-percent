A Node program that writes one original line of plain text — the last text message a phone sends at one percent battery, in the dying phone's own voice — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The message is under 200 characters, makes its last requests with specific, incriminating detail, and is cut off mid-sentence by the death it has been joking about.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
